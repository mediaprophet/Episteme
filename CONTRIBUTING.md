# Contributing to Episteme

We welcome contributions that advance Human-Centric data architectures and W3C Solid adoption.

## The Philosophy
Before contributing, please read the `semantic-dictionary.json` file. All PRs must adhere to the human rights and Rule of Law terminologies established there. We do not accept contributions that introduce architectures designed to lock-in users or commodify personal data.

## How to Contribute
1. **Report Issues**: Check existing issues. If your issue is new, please provide detailed steps and context.
2. **Submit PRs**: 
   - Ensure your code adheres to the `.agents/rules/` constraints.
   - Run the local testing suite (`npm run test`).
   - Describe the human-centric impact of your proposed change.
3. **Extend Rules**: If contributing a new `.md` rule file, make sure to add it to `AGENTS.md`.
