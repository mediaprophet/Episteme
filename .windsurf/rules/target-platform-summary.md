# Episteme Target Platforms Directory Summary

This folder contains deployment-specific cryptographic and session redirect rules for various target platforms.

## Platform Index

*   **01-static-web.md**: Standard web browser constraints (CORS, standard WebCrypto APIs).
*   **02-mobile-native.md**: Mobile-specific secure token storage and crypto polyfills for DPoP.
*   **03-desktop-electron.md**: Electron IPC security protocols and loopback redirection.
*   **04-headless-iot.md**: Server-to-server daemon setups utilizing Client Credentials grant.
*   **05-browser-extension.md**: Manifest V3 security boundaries and launchWebAuthFlow setups.
*   **06-obsidian-plugin.md**: Obsidian plugin Vault interface mapping and custom scheme uri redirections.
