# Minimal Solid App Project Context

This is the re-initialization context for the minimal-solid-app example.

## Layout
*   `src/index.js`: Main entry point for the browser application.
*   `src/auth.js`: Handles WebID authentication flow.
*   `config.ttl`: Episteme agent configuration settings.
*   `custom-addons/active-rules.md`: Restricts auth providers.
